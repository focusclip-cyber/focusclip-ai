# 🚀 FocusClip AI

Turn long videos into speaker-focused short clips.

## Vision

FocusClip AI helps creators convert podcasts, webinars, Zoom meetings, and YouTube videos into high-quality Shorts by focusing on one selected speaker.

## MVP Features

- Paste YouTube URL
- Detect speakers
- Select one speaker
- Find best moments
- Generate Shorts

## Future Features

- AI Captions
- Viral Score
- Auto Zoom
- Multi-language
- Auto Thumbnail
- One-click Export
